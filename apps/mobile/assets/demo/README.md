# Imagem de exemplo

`headphones.png` é uma ilustração fictícia criada localmente pelo script `scripts/create-demo-image.cjs`, sem download ou imagem de terceiros. Representa o produto demonstrativo Fone de ouvido / Aurora / A1. Nome e marca servem apenas ao cenário de teste, sem identificação ou catálogo real.

Para regenerar com Chrome instalado: `npm run demo:image`. O PNG é incluído no app e não exige câmera, galeria ou acesso à rede.
