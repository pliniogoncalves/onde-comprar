# Onde Comprar?

**Fotografou. Encontrou. Comparou.**

Este pacote contém o contexto inicial para iniciar o MVP no VS Code com Codex.

1. Abra esta pasta no VS Code.
2. Instale a extensão oficial OpenAI Codex e entre com sua conta ChatGPT.
3. Abra o painel do Codex e peça: `Leia AGENTS.md e todos os arquivos de docs/. Não implemente ainda. Proponha o plano do protótipo navegável e as decisões em aberto.`
4. Revise o plano antes de autorizar geração de código.

Arquivos:
- `AGENTS.md`: instruções persistentes para o agente.
- `docs/PRODUCT.md`: visão e escopo do produto.
- `docs/ARCHITECTURE.md`: stack e arquitetura.
- `docs/MVP_PLAN.md`: fases e critérios de aceite.
